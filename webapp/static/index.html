About Concept Lab • LF-CBM

Concept Lab provides an interactive, honest interface for exploring and comparing Phase 1 (Original Label-Free CBM) with Phase 2 (Concept-Quality-Filtered LF-CBM).

Label-Free Concept Bottleneck Models (LF-CBM) construct an interpretable concept bottleneck layer from text corpora without requiring manual concept annotations. Phase 2 applies Concept Quality Filtering (greedy submodular selection on relevance and redundancy) to prune redundant and non-discriminative concepts while preserving classification accuracy.

Scientific Honesty & Technical Disclosures

  • Closed-World Assumption: The models only recognize classes within their training dataset and will always output a prediction from this set, even for out-of-distribution inputs.
  • Softmax Calibration: Raw softmax confidence scores are uncalibrated heuristics. High confidence does not guarantee ground truth correctness.
  • Relevance Metric Selection: The Relevance KPI measures the objective function directly optimized by the filter, so it should not be interpreted as an independent empirical finding.
  • Validation vs Test Split: Accuracy is evaluated on the authors' validation split, which corresponds to the official test splits for CIFAR-10, CIFAR-100, and CUB-200.
  • Zero CDN / Full Offline Operation: All fonts, styling, charts, and model inference run completely locally on 127.0.0.1 with zero external requests.
